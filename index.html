🚀 My Proxy

Unified serverless proxy – TikTok, File Upload, SQLite, Turso, Redis, Email

🔑 Authentication: All endpoints require an X-API-Key header. Set the same key as API_SECRET_KEY in your Vercel environment variables.

🎵 TikTok Proxy

Fetch public TikTok profile data (full user detail, stats, videos, batch).

GET /api/tiktok/user/:username

Full user detail (bio, stats, avatar, videos preview).

curl -H "X-API-Key: your-key" https://my-proxy-kappa-vert.vercel.app/api/tiktok/user/jafernegery
GET /api/tiktok/user/:username/stats

Only follower, following, heart, video counts.

curl -H "X-API-Key: your-key" https://my-proxy-kappa-vert.vercel.app/api/tiktok/user/jafernegery/stats
GET /api/tiktok/user/:username/videos?limit=12

List recent videos with metadata.

curl -H "X-API-Key: your-key" https://my-proxy-kappa-vert.vercel.app/api/tiktok/user/jafernegery/videos?limit=5
POST /api/tiktok/batch

Batch fetch multiple profiles. Body: {"usernames": ["user1","user2"]}

curl -X POST -H "X-API-Key: your-key" -H "Content-Type: application/json" -d '{"usernames":["jafernegery"]}' https://my-proxy-kappa-vert.vercel.app/api/tiktok/batch
GET /api/tiktok/tiktok?username=... (legacy lightweight)
GET /api/tiktok/tiktokFull?username=... (legacy full)

📁 Upload Proxy

Upload and download files (temporary storage in /tmp).

POST /api/upload/upload

Multipart/form-data with field file. Returns file info and download URL.

curl -X POST -H "X-API-Key: your-key" -F "file=@myfile.jpg" https://my-proxy-kappa-vert.vercel.app/api/upload/upload
GET /api/upload/download?file=filename

Download the uploaded file.

curl -H "X-API-Key: your-key" https://my-proxy-kappa-vert.vercel.app/api/upload/download?file=abc123.jpg --output downloaded.jpg

🗄️ SQLite Proxy (sql.js + Redis)

REST API over SQLite with Redis persistence (database survives cold starts).

GET /api/sqlite/db?table=users – list all rows
GET /api/sqlite/db?table=users&id=1 – get one row
POST /api/sqlite/db?table=users – insert {"record":{"name":"John","email":"john@x.com"}}
PUT /api/sqlite/db?table=users&id=1 – update {"updates":{"name":"New"}}
DELETE /api/sqlite/db?table=users&id=1 – delete row
curl -H "X-API-Key: your-key" "https://my-proxy-kappa-vert.vercel.app/api/sqlite/db?table=users"

🔷 Turso Proxy (libSQL)

Edge‑hosted SQLite via Turso. Only one endpoint.

POST /api/turso

Body: {"sql":"SELECT * FROM users WHERE id = ?", "args":[1]}

curl -X POST -H "X-API-Key: your-key" -H "Content-Type: application/json" -d '{"sql":"SELECT * FROM users LIMIT 1","args":[]}' https://my-proxy-kappa-vert.vercel.app/api/turso

⚡ Redis Proxy (Upstash)

REST API for Redis commands: get, set, del, incr.

POST /api/redis

Body examples:

{"command":"set","key":"mykey","value":"hello","ttl":60}
{"command":"get","key":"mykey"}
{"command":"del","key":"mykey"}
{"command":"incr","key":"counter"}
curl -X POST -H "X-API-Key: your-key" -H "Content-Type: application/json" -d '{"command":"set","key":"hello","value":"world"}' https://my-proxy-kappa-vert.vercel.app/api/redis
